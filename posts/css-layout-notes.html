用 CSS Grid 处理博客首页布局

侧栏、文章流、专题区和归档区都在同一个响应式网格里，页面会更稳。

6 min 2,100 字 1,032 浏览 原创笔记
CSSGrid响应式

Grid 的好处是能直接描述二维布局。博客首页这种侧栏加主内容的结构，很适合用 grid-template-columns 解决。

移动端不是简单缩小，而是重新决定信息顺序。个人资料可以先出现，文章列表紧跟其后，辅助模块再往下排。

布局写稳之后，动效和内容变化才不会把页面推得乱七八糟。
